## 💎 设计理念

> **Monolith，取自"永恒之石"。** 知识如刻石般永存。我们相信工具应该安静地服务用户，而不是喧宾夺主。

| 原则 | 说明 |
|:---:|:---|
| 🏠 本地优先 | 所有数据存储在本地，无需联网，完全掌控知识资产 |
| 📝 纯文本驱动 | 笔记即 Markdown 文件，无锁定、无黑盒，随时可迁移、可备份 |
| 🧊 核心极简 | 内核只做最基础的事，高级能力通过插件按需加载 |
| 🍎 Apple 风格 UI | 毛玻璃标题栏、圆角卡片、平滑动画，每个像素都经得起凝视 |
